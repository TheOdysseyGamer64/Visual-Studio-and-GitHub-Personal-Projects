# Contributing Guidelines

Thanks for your interest in contributing to this project! 

## Getting Started

Before contributing, please:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them thoroughly.
4. Commit your changes with a clear and descriptive message.
5. Open a pull request explaining what you changed and why.

## Code Contributions

Please try to:

* Keep code readable and reasonably well documented.
* Follow the existing structure and coding style.
* Avoid unnecessary changes unrelated to your contribution.
* Make sure existing functionality isn't broken.
* Test your changes before submitting a pull request.

## Pull Requests

When opening a pull request, please include:

* A brief description of the changes.
* Any relevant screenshots or examples.
* Information about how you tested the changes.
* Any known issues or limitations.

Pull requests may be modified, rejected, or closed if they don't fit the project's goals or standards.

## Be Respectful

Please keep contributions constructive and respectful. Personal attacks, harassment, discrimination, or deliberately disruptive behaviour are not welcome.

Thanks for helping improve the project!
